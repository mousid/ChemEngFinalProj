# Paper brief: Comparing Regression Models for Materials Property Prediction

**Author:** Sidharth Gopisetty

## Project summary
Discovering new materials with desired properties usually needs expensive experiments or simulations. This project uses machine learning to predict band gap (eV) from chemical composition only. We compare linear regression, Ridge, Lasso, and an MLP, with and without PCA, to see if simple models work and whether PCA or neural nets help.

## Data
- **Source:** Matminer `expt_gap` dataset (experimental band gaps from Zhuo et al., J. Phys. Chem. Lett. 2018).
- **Target:** Band gap in eV.
- **Features:** 132 Magpie compositional descriptors (electronegativity, atomic radius, valence, etc.) from chemical formula.
- **Split:** 80% train / 20% test, fixed seed 42. 5-fold CV on the training set for hyperparameters (regularization, PCA n_components, MLP architecture).

## Methods
1. **Linear regression** – baseline (OLS).
2. **Ridge** – L2 regularization; alpha by 5-fold CV.
3. **Lasso** – L1 regularization; alpha by 5-fold CV; use coefficients for feature importance.
4. **MLP** – two hidden layers; architecture and alpha by 5-fold CV.
5. **PCA** – fit on training data only; try several n_components (e.g. 10, 20, 40, 90% variance); run Linear, Ridge, Lasso, MLP on PCA-transformed features.
6. **Metrics:** Mean absolute error (MAE, eV) and R² on the held-out test set.

## Research questions
1. Can we predict band gap from composition with reasonable accuracy using linear models?
2. Does PCA preprocessing improve or hurt performance, and which model benefits most?
3. Do neural networks meaningfully outperform regularized linear models?

2. **Data and features** – expt_gap, Magpie descriptors, train/test split, sample size.
3. **Methods** – each model and how hyperparameters and PCA are chosen; metrics (MAE, R²).

If your run gave **negative R²** or huge MAE (e.g. full dataset with 6353 samples), that usually means a bug or bad scaling/split. For the paper, use a run where R² is between 0 and 1 and MAE is under ~1 eV (e.g. with `MAX_SAMPLES = 2000` in `run_experiments.py`). Paste that run’s summary table and Lasso top-15 into the brief or into the chat when asking for the paper.
